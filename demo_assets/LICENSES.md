# 演示音频授权台账

`demo_assets/` 只能放入已完成下列检查的最终短音频：

1. 说话人明确同意对应用途（现场播放、评委提交包、公开 GitHub 分别确认）；
2. 不包含未授权私人谈话、商业音乐或其他隐私内容；
3. 已核对来源、参考文本、文件 SHA-256 和用途；
4. 已通过完整端到端、盲听与连续三次演示验收。

当前没有团队录音获得公开发布许可，因此本目录下暂无正式音频。

## 正式记录格式

| 文件 | 来源 | 说话人 | 允许现场播放 | 允许评委包 | 允许公开 GitHub | SHA-256 | 确认日期 |
|---|---|---|---|---|---|---|---|

> 不得用“团队自录”代替逐位说话人的具体授权。
> `文件` 必须填写仓库相对路径（例如 `demo_assets/example.wav`）；公开门禁测试会核对路径、`允许公开 GitHub=yes` 与文件 SHA-256。
