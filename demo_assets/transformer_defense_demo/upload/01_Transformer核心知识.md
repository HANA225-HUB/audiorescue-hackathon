# Transformer 核心知识

## 1. 为什么提出 Transformer

传统 RNN 和 LSTM 按时间步顺序处理序列，训练阶段的并行能力受限。距离较远的信息需要经过多个时间步传递，依赖路径较长。Transformer 不再把循环结构作为核心，而是通过注意力机制，让序列中任意两个位置直接交互。

准确的表述是：Transformer 提高了训练阶段处理已知序列的并行度，并缩短了长距离信息交互路径。原始自回归解码器在推理时仍然需要逐步生成，不能说整个 Transformer 推理过程完全并行。

## 2. 自注意力与 Q、K、V

输入表示 `X` 经过三组线性投影得到：

- `Q = XW_Q`：Query，表示当前位置想寻找什么信息；
- `K = XW_K`：Key，表示每个位置可以怎样被匹配；
- `V = XW_V`：Value，表示匹配后真正被汇总的信息。

缩放点积注意力为：

`Attention(Q, K, V) = softmax(QK^T / sqrt(d_k)) V`

计算过程：

1. `QK^T` 计算每个位置对其他位置的相关性分数；
2. 除以 `sqrt(d_k)`，控制高维点积的数值尺度，避免 softmax 过度饱和；
3. softmax 把分数转成注意力权重；
4. 根据权重对 Value 加权求和，得到融合上下文后的表示。

## 3. 整体结构

输入由词嵌入与位置信息组成。经典编码器层主要包括：

- 多头自注意力；
- 逐位置前馈网络；
- 残差连接；
- 层归一化。

原始 Transformer 解码器还包括：

- 带因果掩码的自注意力，避免当前位置看到未来 token；
- 编码器—解码器交叉注意力，使用解码器表示作为 Query、编码器输出作为 Key 和 Value；
- 前馈网络、残差连接与层归一化。

自注意力负责跨位置的信息混合，前馈网络对每个位置的表示独立使用同一组参数进行非线性加工。

## 4. 位置编码

单纯的自注意力只根据内容计算相关性，本身不包含词序。Transformer 需要额外加入位置表示。原始论文使用不同频率的正弦和余弦位置编码，后续模型也常使用可学习位置编码或相对位置编码。

准确的答辩表达是：Transformer 不是“没有顺序信息”，而是通过显式的位置表示注入顺序信息，而不是依靠循环结构逐步传递。

## 5. 多头注意力

多头注意力使用多组独立的投影参数，在不同表示子空间中并行计算注意力，最后拼接并进行线性映射：

`MultiHead(Q, K, V) = Concat(head_1, ..., head_h) W_O`

不同注意力头有能力学习不同类型的关系，但不能保证某个头一定固定负责语法、指代或情感。

## 6. 优势与局限

优势：

- 训练阶段可并行处理整个已知序列；
- 任意两个位置可以直接交互；
- 多头机制可以从多个表示子空间建模关系；
- 架构扩展性强，已用于文本、视觉和语音等任务。

局限：

- 标准全局注意力的主要计算量通常随序列长度近似平方增长；
- 注意力矩阵的内存开销也随序列长度近似平方增长；
- 必须额外注入位置信息；
- 自回归生成阶段仍需要逐 token 解码；
- 长序列任务通常需要窗口、稀疏注意力、分块或其他高效变体。

## 7. 三句总结

1. Transformer 用注意力取代循环，成为核心的信息交互方式。
2. Q、K、V 动态决定每个位置应该关注谁、读取什么。
3. 位置编码、多头注意力、前馈网络和多层堆叠共同形成完整模型。

Transformer 的本质不是简单地“看见所有词”，而是让每个位置根据当前任务，动态选择并聚合更有价值的上下文。
