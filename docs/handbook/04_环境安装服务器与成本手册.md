## 2. 环境原则

### 2.1 本地优先

现场主演示必须能在本地、断网状态下启动。远端算力、隧道、临时域名或在线模型准备都不能成为主演示必需条件。

### 2.2 提前准备

网络可用时只做准备工作：

1. 创建项目虚拟环境；
2. 按仓库固定依赖清单安装项目依赖；
3. 按目标机器要求准备匹配的 PyTorch/TorchAudio；
4. 预热 DeepFilterNet 与 Whisper 资产；
5. 运行 smoke 和离线启动检查；
6. 保存安全摘要。

公开文档只记录版本、测试命令、通过数量和安全摘要，不记录缓存位置或本机路径。

### 2.3 比赛窗口禁止

- 不执行裸 `latest` 安装；
- 不做全量升级；
- 不现场联网下载模型；
- 不临时切换 Python 大版本；
- 不重装 PyTorch/TorchAudio；
- 不清空模型资产或环境缓存；
- 不通过公开 PR 或 Issue 分享服务器地址、账号、端口、日志、token 或远端路径。

## 3. 安装入口

唯一公开安装入口：

```bash
python -m pip install -r requirements.txt
python -m pip check
```

PyTorch/TorchAudio 由环境负责人按目标机器提前准备，并在本地私有记录中确认版本匹配。公开报告只写“matched pair verified”或“pending”，不写具体缓存路径。

---

## 4. 验证入口

轻量验证，不运行真实 ASR 或增强：

```bash
python -m py_compile app.py core/*.py ui/*.py scripts/*.py
python -m unittest discover -s tests -p "test_*.py" -q
git diff --check
```

完整 smoke 只在模型资产和授权短样例已准备好之后运行：

```bash
python scripts/smoke_audio_core.py --normalize-only
python scripts/smoke_audio_core.py --runs 2 --asr-model base --device auto
```

公开报告只发布安全 JSON 摘要字段、测试数量和 pass/fail 状态。

## 5. 服务器 SAFETY-HOLD

服务器不是默认交付路径。当前公开文档不提供远端初始化、上传、同步或远端运行命令。

如未来确需服务器：

- 必须由 C 发布新的明确派单；
- 必须使用脱敏、安全摘要；
- 必须避免公开服务器地址、账号、端口、凭据、路径或日志；
- 必须确认不会接触私有音频、私有文本或保留评测数据；
- 不得把服务器结果包装成正式现场速度证据，除非 C 明确解除 provisional 状态。

## 6. 成本判断

本项目 P0 是短音频增强、双路转写和本地页面展示，不训练模型。默认不租服务器。

只有出现以下阻塞，才进入“是否租用远端资源”的人工讨论：

1. 本地准备环境无法在可接受时间内稳定；
2. 已授权短样例在本地耗时超过演示硬上限；
3. 目标机器兼容性问题无法在比赛窗口内解决；
4. 需要干净 Linux/NVIDIA 环境做备份验证。

任何租用决定都要单独记录成本、使用时长、关闭责任人和安全边界。公开文档只写成本级别和决策结果，不写服务器细节。

## 7. 离线启动检查

断网前：

- 固定 Python 环境已验证；
- 模型资产已预热；
- FFmpeg 可用；
- Gradio 页面可本地打开；
- approved short sample 可处理；
- fixture 与 production 模式边界明确；
- fallback 录屏或预计算结果已准备。

断网后：

- 启动生产 UI；
- 处理 approved short sample；
- 检查 success/partial/failed 语义；
- 检查外部请求为零；
- 检查 delivered files 走受控 opaque route；
- 检查清理只影响本轮临时资源。

---

## 8. 故障处置

| 故障 | 公开处置 |
|---|---|
| 模型资产不可用 | 停止真实处理，使用同版本 fallback，并说明现场模型资产不可用 |
| 转写为空 | 按真实结果展示为空，不手动补文本 |
| partial | 展示可用音频、警告和降级原因，不宣称完整成功 |
| failed | 展示结构化错误，不公开 raw log |
| 网络异常 | 使用离线 fallback，不现场联网下载 |
| 性能过慢 | 切换到已验证短样例或 fallback |
