# 团队总技术手册

> 公共版。本文不记录真实成员、参考文本、候选样例、采集路径、私有数量矩阵或服务器信息。

## 1. P0 范围

AudioRescue P0 是一个离线短音频处理流程：

- 音频标准化。
- A 层增强。
- 双路 ASR。
- A/B 对比、文本差异和结构化证据。
- 本地可运行 UI。

训练模型、实时流、账号系统、移动端和事件分类均不属于默认 P0。

## 2. 代码边界

- `core/schemas.py` 是共享契约源。
- `core/pipeline.py` 是业务编排入口。
- A 层负责 audio I/O、enhance、transcribe 和 smoke evidence。
- B 层负责 UI、文件投递、展示状态和交互。
- C 层负责 schema、pipeline、metrics、cache/events、集成和发布判断。

## 3. 数据边界

- 仓库只跟踪合成 fixture、公开文档和 neutral example spec。
- 私有录音、真实 manifest、本地 spec、模型权重、缓存和运行输出不进 Git。
- 数据工具使用 `configs/dataset_spec.example.json` 展示 schema；真实流程必须显式传入 ignored local spec。
- `reference_text` 只用于指标或人工核对，不能进入模型 prompt。
- Holdout-style split 只在冻结后一次性评测，不用于调参。

## 4. 数据工具

公共数据工具共享 `scripts/dataset_spec.py`：

- `scripts/init_dataset.py`：按 spec 创建本地目录和文本模板，不创建音频。
- `scripts/build_dataset.py`：按 spec 读取标准化 WAV、生成混合样例与 manifest。
- `scripts/validate_dataset.py`：按 spec 校验字段、授权 token、hash、split、路径和 WAV 格式。

本地命令示例：

```powershell
python -m scripts.init_dataset --root data_local --spec <local-spec>
python -m scripts.build_dataset --dataset-root data_local --spec <local-spec>
python -m scripts.validate_dataset data_local --spec <local-spec>
```

## 5. Demo 与交付

Demo assets 必须可公开、可再分发，并使用 neutral filenames。页面和报告不得暴露本机路径、服务器路径、凭据、模型缓存路径、私有参考文本、真实候选 ID 或未授权音频。

## 6. 验证

每个 PR 应按改动范围运行相关单元测试、编译检查和 `git diff --check`。涉及数据工具时，还要扫描 PR diff 和 tracked text，确认只留下 neutral example values 或已说明的外部所有权残留。
